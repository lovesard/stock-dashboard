# 📈 글로벌 주식 분석 대시보드 (Stock Analysis Dashboard)

Streamlit과 yfinance, Plotly를 활용하여 미국 및 한국 주식 데이터를 시각화하고 분석할 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능
1. **미국 및 한국 주식 검색**: 
   - 미국 주식 티커(예: `AAPL`, `TSLA`, `NVDA`)
   - 한국 주식 티커: 코스피(`005930.KS`), 코스닥(`035900.KQ`)
   - 주요 인기 종목 바로가기 프리셋 제공
2. **조회 기간 선택**: 1개월, 6개월, 1년, 5년 중 선택
3. **요약 지표 카드**: 
   - 최근 종가 및 전일 대비 변동폭
   - 선택 기간 동안의 총 수익률(%) 및 가격 변동
   - 선택 기간 최고가 및 최저가
4. **인터랙티브 캔들스틱 차트 (Plotly)**:
   - 캔들스틱 차트 (한국식 색상: 상승-빨강, 하락-파랑)
   - 20일 / 60일 이동평균선(SMA) 오버레이
   - 하단 거래량(Volume) 바 차트 연동
   - 줌, 팬, 툴팁(Hover) 인터랙션 지원
5. **데이터 테이블 및 CSV 다운로드**: 주가 및 이동평균선 데이터를 표로 확인하고 CSV 다운로드 가능

---

## 🛠️ 1. 패키지 설치 방법

터미널(또는 명령 프롬프트 / PowerShell)에서 다음 명령어로 필수 라이브러리를 설치합니다:

```bash
pip install streamlit yfinance plotly pandas
```

또는 `requirements.txt`가 있는 디렉토리에서:

```bash
pip install -r requirements.txt
```

---

## 🚀 2. 앱 실행 방법

`app.py` 파일이 있는 디렉토리로 이동한 후 아래 명령어를 실행합니다:

```bash
streamlit run app.py
```

명령어를 실행하면 자동으로 기본 브라우저에 `http://localhost:8501` 주소로 대시보드가 열립니다.
